**Tech Stack:** Python 3.10+, asyncio, FastAPI (settings app, already present), pytest. **No new dependencies.**

**Spec:** `docs/production-hardening-spec.md` §9 (VAD), §18 (event catalog), §23 (health), §24 (supervisor) — plus the GitHub issue bodies #1–#11 (each issue body is the binding per-task spec; this plan repeats their exact requirements) and `docs/audits/AUDIT_REPORT_2026-08-18.md` (the #5/#6 doc-claim findings).

## Global Constraints

- Python floor is **3.10**: no `asyncio.timeout()`, no `StrEnum`. Ruff line length **110**.
- Run everything through uv. Canonical check before claiming any task done: `uv run ruff check . && uv run pytest`.
- **Never store, log, or expose the OpenAI API key.** Fake keys in tests must look fake: `sk-test-...`. All redaction flows through `reachy_openai_realtime/observability/events.py:redact_secrets` — one source of truth, never a second regex.
- **Never reboot or suspend the OS.** Recovery tops out at rebuilding the app session (the outer loop in `main.run()`).
- Flight-recorder writes must never raise into the voice path. `EventRecorder.record()` already guarantees this; every new `record_event` call site inherits it — do not wrap call sites in try/except.
- No blocking I/O added to `_record_loop` or the receive loop. Health/gauge updates are in-memory only.
- Two event vocabularies, never mixed: user-visible `add_event`/`set_phase` strings are Japanese + i18n keys; flight-recorder `record_event` names are English dotted (`realtime.connected`).
- TDD every task. Conventional commits with `Closes #N` footers. Never `git add -A` without `git status` first. Never bypass hooks.
- Do not edit `docs/production-hardening-spec.md` (verbatim document) or issue history — corrections go in plans and issue comments.

**Interfaces:**
- Produces: `RuntimeStatus.set_component_health(component, healthy, *, expires=True, now=None)`, `RuntimeStatus.health(now=None) -> dict[str, bool]`, `SpeakerWorker.alive() -> bool` (Task 10's supervisor and future dashboards consume these).

Spec §23 shape, exactly: `{"ok": bool, "realtime": bool, "microphone": bool, "speaker": bool, "motion": bool, "camera": bool}`.

**Design decisions (state these in the issue when closing):**
- `ok = realtime and microphone and speaker` — the critical conversational path. Motion and camera are reported but never gate `ok` (spec §25 degradation: keep speaking without motion; §23: disabled camera must not fail global health — with camera outside `ok`, that holds trivially; a disabled camera additionally reports `true` since "not in use" is not "unhealthy").
- Periodic components (microphone, speaker) carry a staleness rule: an update older than 10 s counts unhealthy — a wedged `_record_loop` therefore turns the health it publishes false by itself. Static components (motion, camera) are set once by `main.run()` with `expires=False`.
- `realtime` reads the existing `self._connected` (same source `snapshot()` uses) — no second connection flag.
- Motion health v1 means "MotionController started and not closed"; a live thread-heartbeat waits for the MotionManager rework (#13) — note that on the issue.

- [ ] **Step 3: Implement in `runtime_status.py`**

Add `import time` to the module imports, `_HEALTH_STALE_SECONDS = 10.0` at module level, `self._component_health: dict[str, tuple[bool, float | None]] = {}` in `__init__`, and:

```python
def set_component_health(
    self, component: str, healthy: bool, *, expires: bool = True, now: float | None = None
) -> None:
    stamp = (time.monotonic() if now is None else now) if expires else None
    with self._lock:
        self._component_health[component] = (healthy, stamp)

def _component_ok_locked(self, component: str, now: float) -> bool:
    entry = self._component_health.get(component)
    if entry is None:
        return False
    healthy, stamp = entry
    if stamp is not None and now - stamp > _HEALTH_STALE_SECONDS:
        return False
    return healthy

def health(self, now: float | None = None) -> dict[str, bool]:
    """Component health per hardening spec §23. ok tracks the critical
    conversational path only; motion/camera are reported, never gating."""
    current = time.monotonic() if now is None else now
    with self._lock:
        realtime = self._connected
        microphone = self._component_ok_locked("microphone", current)
        speaker = self._component_ok_locked("speaker", current)
        motion = self._component_ok_locked("motion", current)
        camera = self._component_ok_locked("camera", current)
    return {
        "ok": realtime and microphone and speaker,
        "realtime": realtime, "microphone": microphone, "speaker": speaker,
        "motion": motion, "camera": camera,
    }
```

```python
# ABOUTME: Supervisor policy for the self-healing ladder (hardening spec §24):
# ABOUTME: pure, clock-injected classes; wiring lives in realtime.py / main.py.
from __future__ import annotations

from collections import deque

SUPERVISOR_POLL_SECONDS = 5.0
FSM_INACTIVITY_LIMIT_SECONDS = 120.0
ESCALATION_PAUSE_SECONDS = 30.0


class RestartBudget:
    """Counts session rebuilds in a sliding window; True means escalate.

    Escalation = full media re-init + a longer pause, recorded as
    supervisor.escalated. Never an OS reboot (spec §24)."""

    def __init__(self, *, limit: int = 5, window_seconds: float = 600.0) -> None:
        self._limit = limit
        self._window = window_seconds
        self._restarts: deque[float] = deque()

    def record_restart(self, now: float) -> bool:
        self._restarts.append(now)
        while self._restarts and now - self._restarts[0] > self._window:
            self._restarts.popleft()
        return len(self._restarts) >= self._limit
```
